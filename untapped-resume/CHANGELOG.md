# Changelog

## 0.3.0 — 2026-10-22

First release (numbered with the other Untapped plugins' release, v0.3.0).

- Local evidence scanning for documents, git metadata and LinkedIn export ZIPs.
- One-posting requirement parsing and optional user-supplied HTTPS fetch.
- Source-required resume generation in DOCX, PDF and TXT with a line source map.
- Self-contained portfolio ordered by the agent's evidenced fit assessment.
- Conservative ATS text, source, coverage and layout checks.
- Shared skill for a LinkedIn kit, cover letter, match table and honest gap plan.
- Offline fixtures/tests, Codex/Claude manifests, marketplace registration and MCPB packaging.
