# Untapped Reviews & Maps

Untapped Reviews & Maps helps owners of local businesses finish everyday review and Google Maps tasks. Paste the review or profile details, upload a screenshot, or describe the problem. It works from the information you share and returns text you can paste, followed by up to three short steps.

- **Reply to reviews** writes calm, personal replies and explains when a review may break Google's rules. Sensitive businesses get replies that protect customer privacy.
- **Ask for reviews** writes neutral requests for texts, emails, conversations, cards, or receipts and checks an existing request.
- **Profile checkup** returns a fix list in priority order with supported replacement text.
- **Fix Maps problem** helps with visibility, suspension, verification, edits, duplicate profiles, fake reviews, and suspicious calls.

The plugin has no server. It cannot log in, change your profile, report a review, or promise rankings. You carry out the steps yourself. Missing facts stay missing. Rule notes quote Google's and the FTC's own pages, read on 2026-10-22; follow the linked official pages for current guidance. Do not paste private customer details.

## Install

- **Claude Code:** `/plugin install untapped-reviews-maps --marketplace CTF-Max/untapped-plugins`
- **Codex or the ChatGPT desktop app:** `codex plugin marketplace add CTF-Max/untapped-plugins`, then
  `codex plugin add untapped-reviews-maps@untapped-plugins` (or restart the desktop app and install it from the
  Plugins Directory under Find Untapped Growth).
